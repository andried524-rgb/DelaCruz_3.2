# Assessment 3.2: Linear Data Structure
Name: DELA CRUZ

Dynamic, menu-driven Python programs based on the algorithms in Assessment 3.1.
Each program is in its own file:

| File | Structure | Operations |
|------|-----------|------------|
| array_program.py | Array | append, delete, display |
| linked_list_program.py | Linked List | insert at tail, delete from head/value, display |
| stack_program.py | Stack (LIFO) | push, pop, peek, display |
| queue_program.py | Queue (FIFO) | enqueue, dequeue, front, display |

Run: `python array_program.py` (same for the others). Option 5 in each menu runs the DELA CRUZ demo.
